# my-main-page

Одностраничное портфолио. Весь сайт — один самодостаточный файл `index.html`
(CSS и JS встроены), внешних зависимостей нет, кроме Google Fonts.

## Структура

| Файл                 | Назначение                                        |
|----------------------|---------------------------------------------------|
| `index.html`         | вся страница: разметка, стили, скрипты            |
| `nginx.conf`         | конфиг сервера: gzip, кэш, заголовки безопасности |
| `Dockerfile`         | образ на `nginx:1.30-alpine-slim`, запуск от `nginx` (uid 101) |
| `docker-compose.yml` | публикация на `127.0.0.1:8080`, лимиты ресурсов   |

## Локальная разработка

НИКАКИХ локальных серверов и сборок: для проверки изменений просто откройте
`index.html` в браузере (`file://`). Страница самодостаточна, Google Fonts
подтягиваются по сети, так что `python -m http.server` и подобное не нужны.

## Запуск в Docker (только прод)

Docker-инфраструктура нужна исключительно для продакшн-развёртывания.
Не используйте её для локальных проверок — см. раздел выше.

```bash
docker compose up -d --build     # собрать и поднять
docker compose logs -f           # логи
docker compose down              # остановить
```

Проверка:

```bash
curl -I http://127.0.0.1:8080/          # 200, gzip, Cache-Control: no-cache
curl    http://127.0.0.1:8080/healthz   # ok
```

Замеры: образ 20.6 МБ на диске (~5.7 МБ в реестре), потребление в простое
~3.7 МБ RAM и 0% CPU.

## Развёртывание

Контейнер отдаёт **обычный HTTP на порт 8080** и слушает только loopback —
TLS, HTTP/2 и редиректы остаются за внешним прокси.

Пошаговая инструкция: [`DEPLOY.md`](DEPLOY.md). Коротко, на уже настроенном
сервере:

```bash
cd /srv/portfolio && git pull && docker compose up -d --build
```

## Особенности, о которых легко забыть

- Контейнер работает с `read_only: true`, поэтому в `nginx.conf` все временные
  пути и pid-файл переопределены на `/tmp` (смонтирован как tmpfs).
- `add_header` в nginx наследуется только если на вложенном уровне нет своих
  `add_header`. Поэтому политика кэширования задана через `map $sent_http_content_type`,
  а не отдельным блоком `location` — иначе заголовки безопасности пропадали бы.
- В `index.html` дорога в разделе «Опыт» строится скриптом. Позиции развязок
  берутся из `offsetTop`, а не `getBoundingClientRect()`: у карточек в момент
  замера активен `transform` от scroll-reveal, который сдвигает rect.
- SVG — заменяемый элемент: у `.road` обязана быть явная `height`, иначе
  браузер подставит собственный размер 300×150.

## Источник данных

Содержимое разделов «Опыт», «Навыки», «Образование» и «Проекты» перенесено из
резюме `assets/Daniil_Mishin_CV.pdf`. При обновлении резюме синхронизируйте
страницу — расхождение заметят в первую очередь.

Исключения, которых в резюме нет: ITPU в разделе образования, а также проекты
SK21 CTF Platform и Battle of Fortresses.

## Контакты в разметке

Почта встречается в трёх местах: ссылка в списке контактов, ссылка в футере и
константа `CONTACT_EMAIL` в скрипте (её использует контактная форма). При смене
адреса нужно править все три — форма молча уедет на старый, если про неё забыть.
